# Saksham Ojha

Portfolio site for a full-stack and applied AI developer at IIT Roorkee.

**Live:** [skx56.github.io](https://skx56.github.io/)

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

```bash
npm run build
```

The static export is written to `out/`. Pushing `master` runs `.github/workflows/deploy.yml` and publishes that folder to GitHub Pages.

## Edit

- Resume: `public/SakshamOjha_Resume.pdf`
- Portrait: `public/avatar.jpg`
- Sections: `components/`
